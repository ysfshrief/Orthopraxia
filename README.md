# Orthopraxia — نظام إدارة الخلوة

نظام ويب / PWA لإدارة خلوة اجتماع الشباب: البرنامج، الفرق، المخدومين، الحضور بالـQR، النقاط، والنتائج.
Mobile-first، سريع، ويعمل أوفلاين (PWA).

**Designed & Developed by: Youssef Shrief — Joe Industries**

## التقنيات
- React 18 + Vite 5
- Firebase (Firestore) — مع **Demo Mode** تلقائي على localStorage عند غياب المفاتيح
- html5-qrcode (ماسح QR) + qrcode (توليد الكارنيهات)
- vite-plugin-pwa (تثبيت على الموبايل + أوفلاين)
- RTL كامل، خط Cairo، هوية بصرية مستخرجة من اللوجو

## التشغيل محلياً
```bash
npm install
npm run dev        # وضع تجريبي فوراً بدون Firebase
```
لربط Firebase: راجع `FIREBASE_SETUP.md`.

## النشر على Vercel
1. ارفع المشروع على GitHub.
2. من Vercel: **New Project → Import** المستودع.
3. Framework preset: **Vite** (يُكتشف تلقائياً). Build: `npm run build`، Output: `dist`.
4. (اختياري) أضف متغيرات Firebase في **Environment Variables** — انظر `FIREBASE_SETUP.md`.
5. **Deploy**.

`vercel.json` مضبوط لإعادة التوجيه للـSPA.

## الصفحات
- **الرئيسية**: لوجو + نبذة + وصول سريع + دخول أدمن مخفي (3 ضغطات على اللوجو بالأسفل → `000`).
- **البرنامج**: مقسّم بالأيام، قابل للتعديل من الأدمن. عمود «المقدم» غير موجود. الخانات الفارغة تبقى فارغة.
- **النتائج**: Leaderboard قابل للإخفاء/الإظهار من الأدمن.
- **الحضور**: ماسح QR للمنظم (اختيار فريق + فقرة، تقدّم X/N، منع التكرار، احتساب من يكتمل).
- **الفيديوهات / المسابقة / الصلاة والتسبحة**.
- **لوحة التحكم**: نظرة عامة، الفرق، المخدومين + الكارنيهات، الحضور والنقاط، الإشعارات، الإعدادات.

## نظام الحضور والنقاط (باختصار)
- كل مخدوم له `id` فريد و QR مرتبط به.
- المنظم يصوّر كارنيه المخدوم (المخدوم لا يصوّر نفسه).
- التقدّم يعتمد على **عدد أعضاء الفريق في قاعدة البيانات** لا رقم يدوي.
- منع تسجيل نفس الشخص مرتين في نفس الجلسة، ومنع QR غير مسجّل.
- من يُصوَّر وهو من فريق آخر → يُحتسب في **فريقه هو** وتظهر رسالة بذلك.
- عند اكتمال N/N: يُسجَّل وقت الاكتمال وتُحسب النقاط تلقائياً (نظام النقاط قابل للتعديل بالكامل من الإعدادات).
